# 駿河台西町会 公式サイト

千代田区駿河台西町会の公式サイトです。3ヶ月ごとの「町会からのお知らせ」を掲載します。

---

## ファイル構成

```
surugadai-nishi-chokai/
├── index.html        … サイト本体（編集不要）
├── app.js            … 動作スクリプト（編集不要）
├── notices.json      … お知らせデータ ★更新時はこれを編集
├── assets/
│   └── kamon.png     … 町会の家紋（太田桔梗紋）
├── pdf/              … お知らせPDFの置き場所
│   └── 町会からのお知らせ_2026年5月-7月号.pdf
└── README.md         … この手順書
```

更新時に触るのは原則 `notices.json` と `pdf/` フォルダだけです。

---

## 初回公開の手順（Cloudflare Pages）

### 1. GitHubリポジトリを作る
1. GitHubで新しいリポジトリ（例：`surugadai-nishi-chokai`）を作成
2. この `surugadai-nishi-chokai` フォルダの中身一式をアップロード

### 2. Cloudflare Pagesと連携
1. Cloudflareにログイン →「Workers & Pages」→「Pages」→「Gitに接続」
2. 作成したGitHubリポジトリを選択
3. ビルド設定は以下の通り（ビルド処理は不要な静的サイトです）
   - フレームワークプリセット：`なし`
   - ビルドコマンド：`空欄`
   - ビルド出力ディレクトリ：`/`（ルート）
4.「保存してデプロイ」を押すと、数分で公開されます

### 3. 独自ドメイン（任意）
Cloudflare Pagesの「カスタムドメイン」から、町会の独自ドメインを設定できます。
SSL（https化）は自動で有効になります。

## お知らせを更新する手順

3ヶ月に1度の新しい号を追加する流れです。

### 方法A：管理画面でJSONを作る（おすすめ）

1. 公開サイトのヘッダー右「⚙ 管理」または末尾に `#admin` を付けてアクセス
2. パスワードでログイン（下記「パスワード変更」参照）
3.「＋ 新しいお知らせ」から号の情報を入力
   - 古い号の「最新号」チェックは自動で外れます
4.「notices.json を書き出し」ボタンでファイルを保存
5. 保存した `notices.json` を GitHub リポジトリにアップロードして既存ファイルを差し替え
6. 数分後、公開サイトに自動反映されます

### 方法B：notices.json を直接編集

`notices.json` をテキストエディタで開き、`notices` 配列の先頭に新しい号を追加します。

```json
{
  "id": "n39",
  "vol": 39,
  "issued": "2026年 7月吉日",
  "title": "町会からのお知らせ 2026年 8月〜10月号",
  "period": "2026年 8月 〜 10月 号",
  "range": "2026.07 — 2026.10",
  "topics": [
    "夏祭りの開催について",
    "防災訓練のお知らせ"
  ],
  "pdf": "pdf/町会からのお知らせ_2026年8月-10月号.pdf",
  "pages": "A4・2ページ",
  "tags": ["夏祭り", "防災"],
  "latest": true
}
```

- 新しい号を `latest: true` にしたら、**前の号の `latest` は `false` に変更**してください（最新号は1件だけ）
- `id` は他と重複しない文字列（`n39` など）
- PDFは `pdf/` フォルダに置き、`pdf` 欄にそのパスを書きます
- PDFがまだ無いときは `"pdf": ""` にすると「準備中」と表示されます

### PDFの追加
新しい号のPDFを `pdf/` フォルダにアップロードし、`notices.json` の `pdf` 欄にファイル名を記載します。

## パスワードの変更（重要）

管理画面の初期パスワードは `surugadai` です。**公開前に必ず変更してください。**

`app.js` を開き、以下の行のパスワード部分を書き換えます。

```javascript
if (pass === 'surugadai') {
```

↓ 例

```javascript
if (pass === 'あたらしいパスワード') {
```

### セキュリティについての注意
この管理画面は簡易的なものです。パスワードは `app.js` 内に記述されるため、技術的な知識がある人にはソースを見れば分かってしまいます。本格的なアクセス制限が必要な場合は、Cloudflare Access（無料枠あり）で `/index.html#admin` 以下にアクセス制限をかけることを検討してください。

## こまったときは

- **お知らせが表示されない** … `notices.json` の書式（カンマ、括弧）が正しいか確認。JSONの文法チェックサイトに貼り付けると分かります
- **PDFが開かない** … `pdf/` フォルダにファイルがあるか、`notices.json` のパスが正しいか確認
- **変更が反映されない** … GitHubへのアップロードが完了しているか、Cloudflare Pagesのデプロイが終わっているか確認（数分かかります）
